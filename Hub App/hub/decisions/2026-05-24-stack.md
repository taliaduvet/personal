# Stack choice · 2026-05-24

## Decision
React 18 + Vite + TypeScript + React Router + Supabase JS + brand.css (no Tailwind).

## What we considered
- Option A (React + Vite + Supabase + Tailwind 4) — recommended in the handoff
- Option B (Next.js + Supabase + Tailwind) — heavier, SSR, better for public pages
- Option C (Astro + React islands + Supabase) — most static-first

## Why this choice
Option A was selected. Tailwind 4 was not added because the brand system in `brand.css` is already a complete component library (`.btn`, `.card`, `.input`, `.pill`, surface helpers, etc.). Importing it directly as a plain CSS file is simpler and keeps the design system as the single source of truth without porting tokens into a second system.

React Router v7 handles client-side routing. Supabase JS v2 handles auth and future data needs.

## Tradeoffs
- No SSR — fine for a logged-in app, not needed for SEO
- brand.css is the style system, not utility classes — this is intentional and matches how the design files are structured
