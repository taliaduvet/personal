# Mom's Parking Lot

A simplified solo task board forked from Couples Parking Lot.

## Open the app

```bash
cd mom-parking-lot-app
npm install
npm run dev
```

Then open **http://127.0.0.1:4173/** in your browser (do not double-click `index.html`).

## Features

- **Columns:** People · General todos · Repeated stuff
- **Projects** view (renamed piles) for grouped work
- **Today** and **Focus** (side-by-side: Repeating | Selected)
- **Notes** with highlight → Turn into task on every note surface
- **Archive** calendar with search
- **Device sync** via Settings link code (uses Supabase when `config.js` is set)
