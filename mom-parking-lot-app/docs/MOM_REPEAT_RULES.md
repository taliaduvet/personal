# Mom's Parking Lot — repeat rules

Semi-monthly tasks use a short rule string in the task editor:

| Example | Meaning |
|---------|---------|
| `days:1,15` | Due on the 1st and 15th of each month |
| `every:14 from:2026-01-15` | Every 14 days starting from anchor date |

Add more rule types here as real tasks are identified.
