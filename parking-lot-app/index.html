See today's meetings and weekly capacity so you can plan realistically. Requires a free Google Cloud Client ID — show me how →

  1. Go to console.cloud.google.com and create a new project (any name).
  2. Go to APIs & Services → Library and enable Google Calendar API.
  3. Go to APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID.
  4. Application type: Web application. Add your app URL (e.g. ) under Authorized JavaScript origins.
  5. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it below.
